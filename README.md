# 风暴前线 · 气象闯关

一款可直接在浏览器中打开的单文件气象主题飞机闯关游戏。

## 运行

无需安装依赖。下载 Release 中的 `气象飞机大作战.html`，用现代浏览器打开即可。

支持电脑和移动设备，游戏数据保存在当前浏览器本地。

## 项目特点

- 气象主题的飞行闯关玩法
- Canvas 绘制与原生 JavaScript 实现
- 单文件发布，离线即可运行
- 支持玩家自定义本地账号密码

## 说明

这是个人开发中的独立作品，当前仓库主要用于展示和体验。游戏内的密码只用于本地浏览器存档，不是服务端账号，也不应复用真实网站密码。

## 发布文件

Release 页面提供可直接打开的单文件 HTML。
