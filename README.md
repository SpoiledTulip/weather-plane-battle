# 风暴前线 · 气象闯关

一款面向气象专业学生的单文件气象主题飞机闯关游戏，用轻量互动帮助熟悉天气现象、气象要素和预报思路。

它更适合作为课堂之外的入门体验、复习小工具或气象科普素材，不替代天气学、动力气象学和天气预报课程。

## 在线试玩

打开 [在线试玩](./index.html)，或从 [Releases](https://github.com/SpoiledTulip/weather-plane-battle/releases) 下载单文件版。

## 运行

无需安装依赖。下载 Release 中的 `气象飞机大作战.html`，用现代浏览器打开即可。

支持电脑和移动设备，游戏数据保存在当前浏览器本地。

## 操作

启动后先阅读游戏内教程。电脑端使用键盘控制，移动端使用屏幕触控按钮；具体按键以游戏内提示为准。

主菜单中的“气象知识”按课程主题分章，关卡中的答题和天气图鉴用于复习，不要求先安装 Python、Node.js 或其他软件。

## 项目特点

- 气象主题的飞行闯关玩法
- 将天气现象、气象要素和风险判断放进游戏任务
- 适合作为气象专业学生的课外学习辅助和课堂演示素材
- Canvas 绘制与原生 JavaScript 实现
- 单文件发布，离线即可运行
- 支持玩家自定义本地账号密码

## 适合怎样学习

- **入门认知**：通过游戏中的天气变化和任务提示建立直观印象。
- **概念复习**：把气压、风、降水、雷暴等关键词作为课后复习的触发点。
- **课堂互动**：教师或学生可以直接打开单文件版本，作为讨论天气过程和风险决策的引子。
- **自主拓展**：有编程基础的同学可以阅读源码，尝试增加天气类型、关卡和气象数据可视化。

游戏中的机制是经过简化的互动表达，不能直接当作真实大气过程、业务预报结论或安全决策依据。

## 说明

这是个人开发中的独立作品，当前仓库主要用于展示和体验。游戏内的密码只用于本地浏览器存档，不是服务端账号，也不应复用真实网站密码。

游戏中的天气过程、数值和判定经过游戏化简化，不能直接作为业务预报、航空运行或其他安全决策依据。
